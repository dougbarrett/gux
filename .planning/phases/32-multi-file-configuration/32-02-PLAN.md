**2. Add parseSizeString function (cmd/gux/model.go):**

```go
func parseSizeString(s string) (int64, error)
```

Rules:
- Trim whitespace, convert to uppercase for suffix matching
- Supported suffixes: `B`, `KB`, `MB`, `GB` (case-insensitive)
- Strip whitespace between number and suffix (e.g., "5 MB" works)
- Return int64 byte count
- Multipliers: B=1, KB=1024, MB=1024*1024, GB=1024*1024*1024
- Plain number (no suffix) treated as bytes
- Return error for invalid input
- Match longest suffix first to avoid "B" matching before "KB/MB/GB"
