**1. Core helpers (core/storage.go):**

Add two exported helper functions:
- `ParseFileKeys(jsonStr string) []string` - Parses a JSON-encoded string array. Returns nil if empty string or invalid JSON. Uses `encoding/json.Unmarshal`.
- `SerializeFileKeys(keys []string) string` - JSON-marshals a string slice. Returns `"[]"` for nil/empty.

**2. CRUD multi-file support (core/crud.go):**

Add `MultiFileFields []string` to `CRUDModel` struct.

Add option:
```go
func WithMultiFileFields(fields ...string) CRUDOption {
    return func(m *CRUDModel) { m.MultiFileFields = fields }
}
```

Create `getMultiFileFieldValues(item interface{}, multiFileFields []string) map[string][]string` - for each field name, reads string value via reflection, calls ParseFileKeys, returns map of field->keys.

Extend delete cleanup in `handleDelete`: after getting single-file keys via existing `getFileFieldValues`, also call `getMultiFileFieldValues` for MultiFileFields. Delete all keys from both sources.

Extend update cleanup in `handleUpdate`: before update, capture old multi-file values. After update, compare old vs new arrays, delete keys that were removed (present in old but not in new).

Extend `populateFileInfoFields`: add detection for `[]*FileInfo` DTO fields (check if field type is a slice where element type is `*FileInfo`). When found, parse the model's string field as JSON array via `ParseFileKeys`, convert each key to `*FileInfo` using `FileInfoFromKey`, assign the slice to the DTO field.

**3. Upload endpoint directory support (core/upload.go):**

Use the optional interface approach for backward compatibility:
```go
type DirPutter interface {
    PutInDir(dir, filename string, data io.Reader) (string, error)
}
```

In `handleUpload`: read `dir := r.URL.Query().Get("dir")`. Validate: reject with 400 if contains `..`, `/`, or any character other than `[a-zA-Z0-9_-]`. If dir is set and storage implements `DirPutter`, call `PutInDir` instead of `Put`. The returned key from PutInDir includes the dir prefix (e.g., `gallery/ab/abc123.jpg`).

**4. Implement DirPutter on LocalStorage (core/storage_local.go):**

```go
func (s *LocalStorage) PutInDir(dir, filename string, data io.Reader) (string, error) {
    // Same logic as Put but with dir prefix:
    // 1. Hash content, compute key (same as Put)
    // 2. Create directory: basePath/dir/xx/
    // 3. Write file to basePath/dir/xx/hash.ext
    // 4. Return key as "dir/xx/hash.ext"
}
```

The simplest implementation: call the existing Put logic but with the base path temporarily set to `basePath/dir`, then prepend `dir/` to the returned key. Or factor out the core logic into an internal method that accepts a prefix.

**ui/multi_file_upload.go (shared SSR + props):**

```go
type MultiFileUploadProps struct {
    Accept           []string        // Allowed MIME patterns
    MaxSize          int64           // Max file size in bytes (0 = no limit)
    UploadURL        string          // Upload endpoint (default: "/__gux_api/upload")
    Placeholder      string          // Add zone text (default: "Click to add or drag and drop")
    Class            string          // Additional CSS classes
    Disabled         bool            // Disable interaction
    Values           []string        // Current file URLs for display
    OnUploadComplete func(result UploadResult)  // Called after each successful upload
    OnRemove         func(index int)             // Called when removing file at index
    OnError          func(err string)            // Called on validation/upload errors
}
```

`MultiFileUpload(props MultiFileUploadProps) core.Node` renders:
- Outer container div with border, rounded corners
- File list: for each URL in Values, render a flex row with:
  - If image URL (check extension): `<img>` thumbnail (h-12 w-12 rounded object-cover)
  - If non-image: file icon (Unicode document character) + filename (extracted from URL path)
  - Remove button (X) on the right side, with `data-mfu-remove="{index}"` attribute
- Add zone at bottom: dashed border div with plus icon and placeholder text
- Hidden `<input type="file" multiple>` element
- Uses atomic counter for unique IDs (same pattern as FileUpload)
- Stores props reference for WASM via OnMount callback
