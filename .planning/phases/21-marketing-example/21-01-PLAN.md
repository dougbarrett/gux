<task type="auto">
  <name>Task 2: Create layout.go with MarketingLayout, Nav, Footer</name>
  <files>examples/marketing/pages/layout.go</files>
  <action>
Create the marketing layout infrastructure with responsive navigation:

1. Create `examples/marketing/pages/layout.go`:

**MarketingLayout(r *core.Router, children ...core.Node) core.Node:**
- Full-page wrapper: min-h-screen bg-white dark:bg-gray-900 flex flex-col
- Includes Nav(r) at top
- Main with flex-1 (pushes footer to bottom)
- Footer() at bottom

**Nav(r *core.Router) core.Node:**
- Sticky navigation: bg-white dark:bg-gray-800 shadow-sm sticky top-0 z-50
- Max-w-7xl container with px-4 py-4
- Logo/brand link on left: "MarketCo" linking to /
- Desktop menu (hidden md:flex): Home, Features, Pricing, About, Contact links
- Mobile hamburger button (md:hidden): Unicode hamburger (U+2630) or simple bars
- Mobile menu toggle using r.StateBool("menuOpen", false)
- Mobile menu (conditional): Shows when menuOpen is true, md:hidden
- Link styling: text-gray-600 dark:text-gray-300 hover:text-gray-900 dark:hover:text-white

**navLinks() []core.Node helper:**
- Returns array of 5 nav link nodes
- Used by both desktop and mobile menus

**Footer() core.Node:**
- Dark footer: bg-gray-900 text-gray-400 py-12
- Max-w-6xl container
- 4-column grid (md:grid-cols-4 grid-cols-2):
  - Product: Features, Pricing, Docs (#)
  - Company: About, Blog (#), Careers (#)
  - Support: Contact, FAQ (#), Status (#)
  - Legal: Privacy (#), Terms (#)
- Copyright bar at bottom: border-t border-gray-800 mt-8 pt-8 text-center
- Use ui.Grid for column layout

**footerColumn(title string, links []footerLink) core.Node helper:**
- Renders column with title and link list

**footerLink struct:**
- Text string, Href string

**Hero(title, subtitle string, ctaNodes ...core.Node) core.Node:**
- Full-width hero section: py-20 px-4 bg-gradient-to-br from-blue-600 to-purple-700 text-white
- Max-w-4xl container centered
- H1 with title: text-4xl md:text-5xl lg:text-6xl font-bold mb-6
- P with subtitle: text-xl md:text-2xl text-blue-100 mb-8 max-w-2xl mx-auto
- CTA buttons container: flex flex-col sm:flex-row gap-4 justify-center

**Section(title, description string, children ...core.Node) core.Node:**
- Generic section wrapper: py-20 px-4
- Max-w-6xl container
- Optional header (if title not empty): text-center mb-12
- H2: text-3xl font-bold text-gray-900 dark:text-white mb-4
- P description: text-lg text-gray-600 dark:text-gray-400 max-w-2xl mx-auto
- Children rendered after header
