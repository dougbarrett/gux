<task type="auto">
  <name>Task 1: Create help.go with pattern registry and go.mod parsing</name>
  <files>cmd/gux/help.go, go.mod</files>
  <action>
Create `cmd/gux/help.go` with:

1. **Pattern struct** to hold pattern metadata:
```go
type Pattern struct {
    Name        string // e.g., "page", "page:list"
    Description string // e.g., "Basic page template with OnLoad pattern"
    FilePath    string // e.g., "pages/example.go"
    Template    string // The actual template code
}
```

2. **Pattern registry** as a map:
```go
var patterns = map[string]Pattern{
    // Will be populated in Plan 02
}
```

3. **getModulePath()** function using `golang.org/x/mod/modfile`:
- Read go.mod from current directory
- Use `modfile.ModulePath(data)` to extract module path
- On error or empty result, return "your-module-path" placeholder
- On fallback, print warning to stderr (NOT stdout - keep stdout clean for code output)

4. **printPatternList()** function:
- Iterate patterns map (sorted alphabetically)
- Print: "Available patterns:" header
- Print each pattern: "  {name} - {description}"
- Print empty line then usage hint

5. **runHelpPattern(name string)** function:
- If name is empty, call printPatternList()
- If pattern exists, render it with module path substitution using text/template
- If pattern not found, print error and call printPatternList()

Add dependency to go.mod:
```bash
go get golang.org/x/mod
```

Important implementation notes:
- Use `fmt.Fprintf(os.Stderr, ...)` for warnings (keep stdout clean for piping)
- Sort pattern names alphabetically in printPatternList using `sort.Strings`
- Template output goes to stdout so it can be piped to a file
