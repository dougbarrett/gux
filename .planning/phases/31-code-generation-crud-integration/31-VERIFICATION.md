### Gaps Summary

**1 gap blocks complete goal achievement:**

**Gap: CRUD registration does not include WithFileFields automatically**

- **Problem**: When a developer adds `"input": "file"` to a field and runs `gux gen`, the admin UI is generated correctly (form with FileUpload, detail/list views with previews/thumbnails), BUT the CRUD registration in `app.go` is NOT updated to include `core.WithFileFields("Avatar")`.

- **Impact**: File auto-cleanup (success criterion #4) does NOT work until the developer manually adds `WithFileFields()` to their CRUD registration. This breaks the zero-config promise of the phase goal: "Developer adds `"input": "file"` to a field in gux.config.json and `gux gen` produces **complete** upload integration."

- **Root Cause**: The plan assumed `app.go` CRUD registration is generated by `gux gen` or `gux model`, but it's actually a static template created once by `gux init` and then manually maintained. There is no code generation that updates or creates CRUD registration calls.

- **Evidence**:
  - `cmd/gux/templates/app.go.tmpl` is only used by `gux init`, not `gux gen`
  - No test exists for generating CRUD registration with WithFileFields
  - Plan 02 Task 2 Step 3 says "Find where `app.CRUD(models.X{}, ...)` is generated" but this code is NOT generated
  - Summary claims "Generated CRUD registrations include WithFileFields" but no implementation exists

- **User Experience**: Developer adds `"input": "file"`, runs `gux gen`, scaffolds a User model with Avatar field, sees the FileUpload component in admin forms, uploads a file, saves the user, deletes the user → **file is NOT deleted from storage** because they forgot to add `WithFileFields("Avatar")` to the CRUD registration.

**Possible Solutions**:

1. **Generate app.go CRUD registration** (major change, risky to existing projects)
2. **Output a warning/instruction** when `gux gen` or `gux model` detects file fields:
   ```
   WARNING: File field(s) detected in User model: Avatar
   Add this to your CRUD registration in app.go:
       app.CRUD(models.User{},
           core.WithFileFields("Avatar"),
       )
   ```
3. **Generate a TODO comment** in generated admin files that references the CRUD registration requirement
4. **Document in CLAUDE.md** that WithFileFields must be added manually

Currently option #4 (documentation) exists - CLAUDE.md mentions WithFileFields but doesn't make it clear it's REQUIRED for file cleanup to work.
