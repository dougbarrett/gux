```go
    OnRemove: func() {
        stateVar.Set("")
    },
})
```

### Important implementation notes:

- The model field type stays `string` -- only DTOs use `*core.FileInfo`
- Form state stores the storage key as `string` via `r.StateString`
- When editing, the form needs the key (not the URL) as state initial value. The edit form loads from the model (which has the key as string). The `Value` prop converts key to URL for display.
- The `OnUploadComplete` callback receives `ui.UploadResult` which has `.Key` -- that's what gets stored in state and submitted to the CRUD update endpoint
- When saving the form, the submitted JSON will have the file field as a string (the storage key). The CRUD handler stores this in the model's string field. The DTO serialization (from Plan 01) converts it back to `*FileInfo` for responses.
