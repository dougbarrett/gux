<task type="auto">
  <name>Task 2: Create Users List with Search/Filter and Bulk Actions</name>
  <files>
    examples/admin/pages/users.go
  </files>
  <action>
Create users.go with comprehensive user management:

**Users function:**
- OnLoad fetches all users via api.Users.List
- State for: users (JSON string), searchQuery, roleFilter, statusFilter, selectedJSON (array of uint IDs)

**Search and Filter:**
- Search input (ui.Input with InputSearch type) bound to searchQuery state
- Role filter (ui.Select) with options: All, admin, user, viewer
- Status filter (ui.Select) with options: All, active, suspended, pending
- Apply filters client-side: matchesSearch (name or email contains query), matchesRole, matchesStatus

**Bulk Actions:**
- Parse selectedJSON to []uint for selected IDs
- toggleSelect helper: add/remove ID from selected array
- selectAll/deselectAll helpers
- bulkActionBar: shown when len(selected) > 0
  - Display "{N} users selected"
  - "Deselect All" button (ButtonSecondary)
  - "Delete Selected" button (ButtonDestructive) - opens bulk delete modal
- Bulk delete modal (ui.Modal ModalSM):
  - "Delete {N} Users?" title
  - Warning text about permanent action
  - Cancel and Delete buttons
  - On delete: iterate selected IDs, call api.Users.Delete for each, refresh list

**Users Table:**
- Use ui.Table compound (NOT DataTable, to support checkbox column)
- Header row: Checkbox (select all), Name, Email, Role, Status, Last Login, Actions
- Body rows with capturedUser pattern to avoid closure bug:
  - Checkbox column with isSelected check
  - Name as link to /users/{id}
  - Email
  - Role with roleBadge helper (BadgeError for admin, BadgeSuccess for user, BadgeDefault for viewer)
  - Status with statusBadge helper (BadgeSuccess for active, BadgeError for suspended, BadgeWarning for pending)
  - Last Login (formatted date or "Never")
  - Actions: View link

**Helpers:**
- roleBadge(role string) - returns ui.Badge with appropriate variant
- statusBadge(status string) - returns ui.Badge with appropriate variant
- formatLastLogin(t *time.Time) - "Never" if nil, else formatted date

Add "+ Add User" button at top linking to /users/new
  </action>
  <verify>
    go build ./examples/admin/pages && grep -E "(func Users|selectedJSON|bulkActionBar)" examples/admin/pages/users.go
  </verify>
  <done>
    Users list shows all users with search/filter. Bulk selection works with checkbox column. Bulk delete modal confirms action. Role and status badges display correctly.
  </done>
</task>

Create three user management pages:

**user_detail.go - UserDetail function:**
- Get :id param from r.Param("id")
- OnLoad: api.Users.Get(id) to fetch user detail
- State for user data and showDeleteModal (bool)
- Display in AdminLayout:
  - Back link to /users
  - H1 with user name
  - Info card showing: Email, Role (with badge), Status (with badge), Created At, Updated At, Last Login
  - Action buttons: Edit (link to /users/{id}/edit), Delete (opens modal)
- Delete confirmation modal (same pattern as examples/saas/pages/project_detail.go)
  - On confirm: api.Users.Delete, navigate to /users

**user_edit.go - UserEdit function:**
- Get :id param
- OnLoad: fetch user detail
- State for form fields: name, email, role, status, password (optional), plus error/success messages
- Form with:
  - Name input (required)
  - Email input (required)
  - Role select (admin, user, viewer)
  - Status select (active, suspended, pending)
  - Password input (optional, placeholder "Leave blank to keep current")
- Validation: name and email required
- On submit: build update payload, call api.Users.Update, show success or error
- Cancel button returns to /users/{id}

**user_new.go - UserNew function:**
- State for form fields: name, email, role, status, password, plus error message
- Form with same fields as edit (password required for new user)
- Validation: all fields required, password min 8 chars
- On submit: api.Users.Create, on success navigate to /users
- Cancel button returns to /users

**Shared helpers (can be in layout.go or inline):**
- formField(label string, input core.Node) - wraps label + input
- Use ui.FormField if available, otherwise manual label + input pattern
