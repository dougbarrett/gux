  <name>Task 1: Create Activity Logs Page</name>
  <files>
    examples/admin/pages/activity.go
  </files>
  <action>
Create activity.go with comprehensive activity log viewing:

**Activity function:**
- Package pages, import core, ui, api, dto, encoding/json, time, fmt
- OnLoad: fetch all activity logs via api.ActivityLogs.List
- State for: logsJSON (string for array), actionFilter, entityFilter

**Filter Controls:**
- Action filter (ui.Select): All, created, updated, deleted, login, logout
- Entity filter (ui.Select): All, user, setting

**Filter Logic:**
- Parse logsJSON to []dto.ActivityLogList
- Apply filters client-side:
  - matchesAction: actionFilter empty or matches log.Action
  - matchesEntity: entityFilter empty or matches log.Entity
- Build filtered slice

**Activity Table:**
- Use ui.DataTable[dto.ActivityLogList] with columns:
  - "Time" - format CreatedAt as "Jan 2, 15:04"
  - "User" - display UserName (or "System" if nil/empty)
  - "Action" - use actionBadge helper
  - "Entity" - capitalize first letter
  - "Description" - the log description
- Props: Striped=true, Hoverable=true

**Helpers:**
- actionBadge(action string) - returns ui.Badge:
  - created: BadgeSuccess (green)
  - updated: BadgeDefault (gray)
  - deleted: BadgeError (red)
  - login: BadgeSuccess
  - logout: BadgeWarning
- formatActivityTime(t time.Time) - "Jan 2, 15:04" format
- capitalizeFirst(s string) - capitalize first letter of entity

**Layout:**
- AdminLayout wrapper
- H1 "Activity Logs"
- Filter row with HStack (Gap="4") containing both selects
- DataTable below filters
- Empty state: "No activity logs found" if filtered list is empty

  </verify>

**Settings function:**

**Tab Structure:**
- TabList with 3 tabs: General (0), Security (1), Email (2)

- Tab styling: Class="border-gray-700" on TabList

**generalTab(r *core.Router) []core.Node:**
- State: siteName, siteDescription, timezone, language, successGeneral
- Form fields:
  - Site Name (ui.Input)
  - Site Description (ui.Textarea)
  - Default Timezone (ui.Select with UTC, America/New_York, Europe/London, Asia/Tokyo)
  - Default Language (ui.Select with en, es, fr, de)
- Save button shows success message
- All inputs use dark theme classes: bg-gray-700 border-gray-600 text-white

**securityTab(r *core.Router) []core.Node:**
- State: sessionTimeout, passwordMinLength, twoFactorRequired, successSecurity
- Form fields:
  - Session Timeout (ui.Select: 15 min, 30 min, 1 hour, 4 hours, 1 day)
  - Minimum Password Length (ui.Select: 6, 8, 10, 12, 16)
  - Require Two-Factor (ui.Switch) - settingRow helper
- Role-based section (admin only):
  - Danger Zone card with red border
  - "Reset All User Sessions" button (ButtonDestructive)

- Save button
