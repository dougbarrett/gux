   - Description string (help text, shown only when no error)
   - Class string (additional wrapper classes)

2. `FormField(props FormFieldProps) core.Node` function:
   - Create children slice for building the field
   - If Label is set:
     - Create label with class "block text-sm font-medium text-gray-700 dark:text-gray-300 mb-1"
     - Add asterisk span if Required: core.Span with class "text-red-500 ml-1" containing "*"

   - Append props.Children (the input(s))
   - If Error is non-empty:
     - Add core.P with class "text-sm text-red-600 dark:text-red-400 mt-1" and role="alert"

     - Add core.P with class "text-sm text-gray-500 dark:text-gray-400 mt-1"
