  <name>Task 1: Create Textarea component</name>
  <files>ui/textarea.go, ui/textarea_test.go</files>
  <action>
Create `ui/textarea.go` with:

1. Type definitions:
   - `TextareaResize` string type with constants: `ResizeNone`, `ResizeVertical`, `ResizeBoth`

2. Reuse inputSizeClasses from a shared constant or define locally:
   - sm="px-2 py-1.5 text-sm", md="px-3 py-2 text-base", lg="px-4 py-3 text-lg"
   - Use InputSize type from input.go (import within same package)

3. Class constants:
   - `textareaBaseClasses`: Same as inputBaseClasses (copy or factor out)
   - `resizeClasses` map: none="resize-none", vertical="resize-y", both="resize"

4. `TextareaProps` struct:
   - Size InputSize (default: md) - reuse from input.go
   - Resize TextareaResize (default: vertical)
   - Rows int (default: 3)
   - ID string
   - Name string
   - Value string
   - Placeholder string
   - Class string
   - Disabled bool
   - Required bool
   - Error string
   - OnChange func(string)

5. `Textarea(props TextareaProps) core.Node` function:
   - Apply defaults: Size=InputMD, Resize=ResizeVertical, Rows=3
   - Build class string using MergeClasses with base, size, resize, error, disabled, custom
   - Build core.Attrs with ID, Name, Class, OnChange
   - Build Extra map for: placeholder, disabled, required, rows (as string), aria-required, aria-invalid
   - IMPORTANT: Pass core.Text(props.Value) as child for SSR rendering (textarea needs content as child, not value attr for initial SSR)
   - Return core.Textarea(attrs, core.Text(props.Value))

6. Create `ui/textarea_test.go` with table-driven tests:
   - TestTextarea_DefaultValues: verifies default size, resize, rows

   - TestTextarea_Required: verifies required and aria-required
   - TestTextarea_Error: verifies aria-invalid and error styling
   - TestTextarea_Value: verifies value renders as textarea content (for SSR)
   - TestTextarea_CustomClass: verifies custom class merges

   - ID string

   - Placeholder string (placeholder option text, e.g., "Select...")
   - Class string
   - Disabled bool
   - Required bool
   - Error string
   - OnChange func(string)

4. `Select(props SelectProps) core.Node` function:

   - Build Extra map for: disabled, required, aria-required, aria-invalid
