<task type="auto">
  <name>Task 2: Create RadioGroup component</name>
  <files>ui/radio.go, ui/radio_test.go</files>
  <action>
Create `ui/radio.go` with:

1. `RadioOptionProps` struct:
   - Value string (option value)
   - Label string (display label)
   - Description string (optional help text)
   - Disabled bool

2. `RadioGroupProps` struct:
   - Name string (required - groups radios together)
   - Value string (currently selected value)
   - Options []RadioOptionProps
   - Inline bool (horizontal layout if true, vertical if false)
   - Class string
   - Disabled bool (disables all options)
   - Required bool
   - Error string

3. Class constants:
   - `radioBaseClasses`: "h-4 w-4 text-blue-600 border-gray-300 dark:border-gray-600 focus:ring-blue-500 focus:ring-offset-0 bg-white dark:bg-gray-800"
   - `radioDisabledClasses`: "cursor-not-allowed opacity-50"

4. `RadioGroup(props RadioGroupProps) core.Node` function:
   - Build wrapper class:
     - If Inline: "flex flex-row gap-4"
     - Else: "flex flex-col gap-2"
     - Add props.Class
   - For each option in props.Options:
     - Determine isChecked: opt.Value == props.Value
     - Determine isDisabled: props.Disabled || opt.Disabled
     - Build radio input attrs:
       - Type="radio", Name=props.Name, Value=opt.Value
       - Add "checked": "checked" to Extra ONLY if isChecked
       - Add "disabled": "disabled" if isDisabled
       - Add "required": "required" if props.Required (only on first option typically, but can be on all)
     - Build label wrapper with input + label text (+ optional description)
     - Apply disabled styling to label wrapper if disabled
   - Wrap all options in core.Div with role="radiogroup"
   - If props.Error: consider adding aria-invalid to wrapper

5. Create `ui/radio_test.go` with table-driven tests:
   - TestRadioGroup_Basic: renders radiogroup div with options
   - TestRadioGroup_SelectedValue: verifies checked on correct option only
   - TestRadioGroup_NoSelection: verifies no checked attributes when Value=""
   - TestRadioGroup_Inline: verifies flex-row layout
   - TestRadioGroup_Stacked: verifies flex-col layout (default)
   - TestRadioGroup_DisabledGroup: verifies all options disabled
   - TestRadioGroup_DisabledOption: verifies single option disabled
   - TestRadioGroup_Required: verifies required attribute
   - TestRadioGroup_WithDescriptions: verifies option descriptions render
   - TestRadioGroup_SameName: verifies all radios have same name attribute

  <action>
Create `ui/switch.go` with:

1. Class constants:
   - `switchTrackClasses`: "relative inline-flex h-6 w-11 items-center rounded-full transition-colors duration-200 ease-in-out focus-within:outline-none focus-within:ring-2 focus-within:ring-blue-500 focus-within:ring-offset-2"
   - `switchTrackOnClasses`: "bg-blue-600"
   - `switchTrackOffClasses`: "bg-gray-300 dark:bg-gray-600"
   - `switchKnobClasses`: "inline-block h-4 w-4 rounded-full bg-white transform transition-transform duration-200 ease-in-out shadow"
   - `switchKnobOnClasses`: "translate-x-6"
   - `switchKnobOffClasses`: "translate-x-1"
   - `switchDisabledClasses`: "opacity-50 cursor-not-allowed"

2. `SwitchProps` struct:
   - ID string
   - Name string
   - Checked bool
   - Label string (optional - displayed next to switch)
   - Class string
   - Disabled bool

3. `Switch(props SwitchProps) core.Node` function:
   - Build track class: switchTrackClasses + on/off + disabled if needed
   - Build knob class: switchKnobClasses + on/off position
   - Create hidden checkbox input (for form submission and accessibility):
     - type="checkbox", name, checked attribute if Checked
     - class="sr-only" (screen reader only, visually hidden)
   - Create visual switch using button or div:
     - Use core.El("button") with type="button" for keyboard accessibility
     - Or use label wrapping hidden input
     - Build structure:
       ```
       <label class="...wrapper...">
         <input type="checkbox" class="sr-only" name="..." checked? />
         <span class="...track...">
           <span class="...knob..."></span>
         </span>
         {Label text if provided}
       </label>
       ```
   - Add role="switch" and aria-checked to the visual element
   - Return the composed structure

Note: Since this is SSR+WASM, the checked state is controlled by props.
In WASM, clicking the switch should toggle state via page-level handler, not internal state.
