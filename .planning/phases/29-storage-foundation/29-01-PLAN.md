<task type="auto">
  <name>Task 2: LocalStorage implementation with content hashing and validation</name>
  <files>core/storage_local.go</files>
  <action>
Create `core/storage_local.go` implementing the Storage interface:

1. **LocalStorage struct**:
   ```go
   type LocalStorage struct {
       baseDir      string
       baseURL      string   // default "/__gux_api/files"
       maxSize      int64    // 0 = no limit
       allowedTypes []string // empty = all allowed
       serveAuth    bool     // require auth for serving
   }
   ```

2. **NewLocalStorage(dir string, opts ...StorageOption) *LocalStorage** constructor. Apply defaults, then options. Create baseDir if it doesn't exist (`os.MkdirAll`).

3. **Put method** -- the core implementation:
   a. Validate size: if maxSize > 0 and size > maxSize, return `&StorageError{Code: "file_too_large", ...}`
   b. Read file content into a buffer (need to read for both hashing and MIME detection). Use `io.LimitReader` if maxSize is set to avoid reading beyond limit.
   c. Detect MIME type using `mimetype.Detect(buf)` (uses the byte slice, not reader, since we need to reuse the bytes).
   d. Validate allowed types: if allowedTypes is non-empty, check detected type against patterns using `matchMimePattern`. Return `&StorageError{Code: "type_not_allowed", ...}` on mismatch.
   e. Compute SHA-256 hash of the bytes: `sha256.Sum256(buf)`, format as hex.
   f. Determine file extension from detected MIME type using `mtype.Extension()` from mimetype library.
   g. Build key: `prefix/hashHex+ext` where prefix = first 2 chars of hash.
   h. Create subdirectory: `os.MkdirAll(filepath.Join(baseDir, prefix), 0755)`.
   i. Write file atomically: write to temp file in baseDir, then `os.Rename` to final path.
   j. Detect image dimensions: if content type starts with "image/", seek back to start of buffer and call `image.DecodeConfig`. Import `_ "image/jpeg"`, `_ "image/png"`, `_ "image/gif"` for format registration. If detection fails (e.g., SVG), set width/height to 0 -- don't error.
   k. Return `&UploadResult{Key: key, URL: s.URL(key), Filename: filename, Size: int64(len(buf)), ContentType: mtype.String(), Width: w, Height: h}`.

   IMPORTANT: The `filename` parameter to Put is the ORIGINAL filename from the upload (preserved in metadata only). The stored filename is always the content hash. Do NOT use the original filename for disk storage (path traversal prevention).

   IMPORTANT: Use `bytes.NewReader(buf)` for image.DecodeConfig since we already have the full bytes in memory. Do NOT try to seek on the original io.Reader.

4. **Delete method**: `os.Remove(filepath.Join(baseDir, key))`. Return nil if file doesn't exist (idempotent). Clean up empty parent directory with `os.Remove` (ignore error if not empty).

5. **URL method**: `return s.baseURL + "/" + key` (simple string concatenation, key already has the prefix/hash.ext structure).

6. Add `go get github.com/gabriel-vasile/mimetype` dependency.
