<task type="auto">
  <name>Task 2: Upload endpoint and file serving handler</name>
  <files>core/upload.go</files>
  <action>
Create `core/upload.go` with upload and file serving HTTP handlers:

1. **registerUploadHandlers(mux *http.ServeMux)** -- registers both endpoints:
   - `POST /__gux_api/upload` -- multipart file upload
   - `GET /__gux_api/files/` -- file serving (trailing slash for subtree match)

2. **Upload handler** (`handleUpload`):
   a. **Auth check**: If `a.authConfig != nil` (auth is configured), check session. Get session ID from cookie, look up user. If no valid session, return 401 JSON: `{"error": "unauthorized", "message": "Authentication required"}`. Skip auth check if auth is not configured on the app (backward compat).
   b. **CSRF check**: The upload endpoint is a POST, so it goes through the CSRF middleware automatically (CSRF middleware wraps the entire mux in Handler()). No extra CSRF code needed here -- it's handled by the existing CSRFMiddleware.
   c. **Size limiting**: If storage has maxSize > 0, use `http.MaxBytesReader` to wrap r.Body BEFORE parsing. Access maxSize via a type assertion to *LocalStorage or add a `MaxSize() int64` method to the Storage interface (prefer adding the method to keep it generic). Actually, simpler: add a `Config() StorageConfig` or just handle it at the Storage.Put level -- the Put method already validates size. For the HTTP layer: use `r.ParseMultipartForm(32 << 20)` with 32MB memory limit. If ParseMultipartForm fails, check if it's a size error and return 413.
   d. **Process each file**: Iterate over `r.MultipartForm.File` map. For each file part:
      - Open the file: `part.Open()`
      - Call `a.storage.Put(r.Context(), part.Filename, file, part.Size)`
      - If Put returns a `*StorageError`, add to errors array
      - If Put succeeds, add `*UploadResult` to results array
      - Close the file part
   e. **Clean up**: Call `r.MultipartForm.RemoveAll()` to clean temp files.
   f. **Response**: Return JSON with status 200 on success:
      ```json
      [
        {"key": "ab/abc123.jpg", "url": "/__gux_api/files/ab/abc123.jpg", "filename": "photo.jpg", "size": 12345, "content_type": "image/jpeg", "width": 800, "height": 600}
      ]
      ```
      On validation error (any file fails), return 400 with the StorageError JSON for the first failure.
      On no files in request, return 400: `{"error": "no_files", "message": "No files in upload request"}`.

3. **File serving handler** (`handleServeFile`):
   a. **Auth check** (optional): If storage has `serveAuth` enabled AND auth is configured, check session. Return 401 if not authenticated.
   b. Extract key from URL path: strip `/__gux_api/files/` prefix to get the key (e.g., "ab/abc123.jpg").
   c. **Path traversal protection**: Reject keys containing `..` or starting with `/`. Use `filepath.Clean` and verify the result doesn't escape baseDir.
   d. For LocalStorage: resolve full path as `filepath.Join(baseDir, key)`. Open file with `os.Open`.
   e. If file not found, return 404.
   f. Detect MIME type from file extension using `mime.TypeByExtension`. Fall back to "application/octet-stream".
   g. Set headers:
      - `Cache-Control: public, max-age=31536000, immutable`
      - `Content-Type: {detected type}`
      - `Content-Disposition: inline` for images/PDFs/videos, `attachment` for everything else
   h. Serve with `http.ServeContent(w, r, key, stat.ModTime(), file)` for range request support.
   i. Define `isInlineType(mimeType string) bool` helper: returns true for image/*, video/mp4, video/webm, application/pdf.

4. **Access to LocalStorage internals**: The serve handler needs the baseDir. Add a `ServeHTTP(w http.ResponseWriter, r *http.Request)` method to LocalStorage (or just use a `Serve(key string) (io.ReadSeekCloser, os.FileInfo, error)` method on the Storage interface). Prefer adding to the interface:
   ```go
   // In storage.go, add to Storage interface:
   // Serve returns a reader and file info for serving a file by key.
   // Returns os.ErrNotExist if file not found.
   Serve(key string) (io.ReadSeekCloser, os.FileInfo, error)
   ```
   Then implement in LocalStorage: open file at `filepath.Join(baseDir, key)`, return the os.File (which implements ReadSeekCloser) and its Stat().

   Also add this method to the Storage interface in `core/storage.go` (from Plan 01).

IMPORTANT: The `Serve` method on Storage is needed because the HTTP layer shouldn't know about baseDir or filesystem details. This keeps the abstraction clean for future cloud backends.

IMPORTANT: For the serve handler, ALWAYS validate the key to prevent path traversal. The key must not contain ".." segments and must not be absolute.

Create `core/upload_test.go` with integration tests using httptest:

1. **Helper function** `setupTestApp(t *testing.T, opts ...StorageOption) (*App, *httptest.Server)`:
   - Creates temp dir with `t.TempDir()`
   - Creates App with `New()`
   - Sets storage: `app.SetStorage(NewLocalStorage(tempDir, opts...))`
   - Returns app and `httptest.NewServer(app.Handler())`

2. **Helper function** `uploadFile(t *testing.T, server *httptest.Server, fieldName, filename string, content []byte) *http.Response`:
   - Creates multipart form body with `multipart.NewWriter`
   - Sends POST to `server.URL + "/__gux_api/upload"`
   - Returns response

3. **TestUpload_SingleFile**: Upload a text file. Verify:
   - Status 200
   - Response is JSON array with 1 element
   - Result has non-empty Key, URL, correct Filename, Size, ContentType

4. **TestUpload_MultipleFiles**: Upload 2 files in one request. Verify:
   - Status 200
   - Response array has 2 elements
   - Each has distinct keys

5. **TestUpload_ImageDimensions**: Upload the minimal 1x1 PNG (reuse minPNG from storage_test.go -- define it as a package-level var or use a shared test helper). Verify Width=1, Height=1 in response.

6. **TestUpload_ContentAddressed**: Upload same content twice. Verify same key returned.

7. **TestUpload_FileTooLarge**: Configure WithMaxSize(10). Upload 100 bytes. Verify status 400 and StorageError JSON with code "file_too_large".

8. **TestUpload_TypeNotAllowed**: Configure WithAllowedTypes("image/*"). Upload text file. Verify status 400 and code "type_not_allowed".

9. **TestUpload_NoFiles**: Send POST with empty multipart form. Verify status 400 and code "no_files".

10. **TestServeFile**: Upload a file, then GET its URL. Verify:
    - Status 200
    - Correct Content-Type header
    - Cache-Control header is "public, max-age=31536000, immutable"
    - Body matches original content

11. **TestServeFile_InlineDisposition**: Upload PNG, GET its URL. Verify Content-Disposition is "inline".

12. **TestServeFile_AttachmentDisposition**: Upload text file, GET its URL. Verify Content-Disposition is "attachment".

13. **TestServeFile_NotFound**: GET a non-existent file path. Verify status 404.

14. **TestServeFile_PathTraversal**: GET `/__gux_api/files/../../../etc/passwd`. Verify status 400 or 404 (not a file leak).

15. **TestUpload_WithAuth**: Configure auth on app (`app.EnableAuth(...)` with MemorySessionStore). Upload without session cookie. Verify status 401. Then create a session, set cookie, upload again. Verify status 200.

16. **TestUpload_CSRFProtection**: Enable CSRF on app. Upload without CSRF token. Verify status 403. Then include proper CSRF cookie + header. Verify status 200.

Use table-driven tests with `t.Run()` where appropriate. Use `t.TempDir()` for all filesystem operations.

For CSRF tests: note that the app's Handler() wraps the mux with CSRFMiddleware. You need to:
- First GET any page to receive the CSRF cookie
- Then include both the cookie and X-CSRF-Token header on the upload POST
