3. Render:
   - JSON marshal/unmarshal pattern for hydration
   - DashboardLayout wrapper
   - H1 "Projects" header
   - Add Project button (green, links to /projects/new)
   - ui.DataTable[dto.ProjectList] with columns:

   - Striped=true, Hoverable=true

   - Edit button linking to /projects/:id/edit
   - Delete button that opens confirmation modal

4. Delete modal using ui.Modal:
   - State: deleteModalOpen := r.StateBool("deleteModal", false)
   - Title: "Delete Project"
   - Content: "Are you sure you want to delete this project?"
   - Footer: Cancel button (closes modal), Delete button (calls api.Projects.Delete, navigates to /projects)

   - Validate name is not empty
   - Call api.Projects.Create with data map
   - On success: navigate to /projects
   - On error: show error message
5. Create Project button

**project_edit.go** - Edit form (pattern: admin/user_edit.go):
