Create ui/file_upload.go (NO build tag -- works on all platforms, like video_player.go).

**FileUploadProps struct:**
- Accept []string -- allowed MIME patterns (e.g., "image/*", "application/pdf"). Empty = any type.
- MaxSize int64 -- max file size in bytes. 0 = no limit.
- UploadURL string -- endpoint URL (default "/__gux_api/upload")
- Placeholder string -- text shown in empty state (default "Click to upload or drag and drop")
- Class string -- additional CSS classes on outer container
- Disabled bool -- disable all interaction
- Value string -- current file URL (for edit forms showing existing file)
- OnUploadComplete func(result UploadResult) -- called after successful upload with server response. UploadResult is re-declared here (same shape as fetch.UploadResult but without js dependency).
- OnError func(err string) -- called on validation or upload error
- OnRemove func() -- called when user removes file

**UploadResult struct** (in ui package, no js dependency):
- Key string
- URL string
- Filename string
- Size int64
- ContentType string

**FileUpload function:**
1. Generate unique ID: fmt.Sprintf("gux-upload-%d", fileUploadIDCounter.Add(1)) using atomic.Int64
2. Build the static HTML structure (SSR-safe):
   - Outer div with role="group", aria-label="File upload", tabindex="0"
   - Hidden file input: core.Input with Type="file", ID=id+"-input", Class="sr-only" (visually hidden but accessible), Accept attribute from props (join Accept with comma)
   - Label wrapping the visible drop zone: core.Label with For=id+"-input"
     - Upload icon area (SVG or text icon placeholder)
     - Placeholder text (props.Placeholder or default)
     - Accepted types hint if Accept is non-empty
     - Max size hint if MaxSize > 0
   - Preview container: empty div with ID=id+"-preview" (populated by WASM)
   - Progress container: div with ID=id+"-progress", aria-live="polite" (populated by WASM)
   - Error container: div with ID=id+"-error", aria-live="assertive" (populated by WASM)
   - Status container: div with ID=id+"-status", Class="sr-only", aria-live="polite" (screen reader announcements)
3. Set attrs.OnMount = createFileUploadInit(id, props) -- this is the stub/wasm split point
4. If props.Value is non-empty, render existing file display (thumbnail if image URL, filename link otherwise) with a remove button

**Tailwind classes for the drop zone:**
- Border dashed, rounded, padding, flex column center
- Default: border-gray-300 dark:border-gray-600, bg-gray-50 dark:bg-gray-800
- Hover: border-blue-400 (via CSS, WASM adds drag-over class)
- The drag-over state class "gux-upload-dragover" should change border to blue-500 and bg-blue-50

**Helper functions (in file_upload.go):**
- formatFileSize(bytes int64) string -- human readable (B, KB, MB, GB)
- isImageURL(url string) bool -- checks if URL path ends in common image extensions
- acceptString(accept []string) string -- joins accept list with commas for input accept attribute

  <name>Task 2: Create ui/file_upload_wasm.go (WASM interactivity)</name>
  <files>ui/file_upload_wasm.go</files>
  <action>
Create ui/file_upload_wasm.go with build tag `//go:build js && wasm`.

Import syscall/js, fmt, strings, and github.com/dougbarrett/gux/fetch.

**createFileUploadInit(id string, props FileUploadProps) func(el any):**
Returns an OnMount function that receives the DOM element and wires up all interactivity:

1. **Window-level drag prevention** (prevent browser opening dropped files):
   - addEventListener("dragover", preventDefault) on window
   - addEventListener("drop", preventDefault) on window
   - Use a package-level sync.Once to only register these once

2. **Drop zone drag-and-drop handlers** on the outer element (el):
   - "dragenter": add class "gux-upload-dragover" to el, preventDefault
   - "dragover": preventDefault, set dataTransfer.dropEffect = "copy"
   - "dragleave": remove class "gux-upload-dragover" from el (only if relatedTarget is outside el, use el.Call("contains", e.Get("relatedTarget")) check)
   - "drop": preventDefault, remove dragover class, get files from e.Get("dataTransfer").Get("files"), process first file via handleFileSelected

3. **File input change handler:**
   - Get input element by ID (id + "-input")
   - addEventListener("change", ...) -- get files from input.Get("files"), process first file

4. **handleFileSelected(file js.Value)** (closure capturing id and props):
   a. Clear any previous error, preview, progress
   b. **Validate type**: if props.Accept non-empty, check file.Get("type").String() against each pattern using matchMimePattern. On failure, show error in error container and call props.OnError if set. Return early.
   c. **Validate size**: if props.MaxSize > 0, check file.Get("size") against MaxSize. On failure, show error with human-readable sizes. Return early.
   d. **Image preview**: if file type starts with "image/", create preview using URL.createObjectURL:
      - objURL := js.Global().Get("URL").Call("createObjectURL", file).String()
      - Create img element, set src=objURL, add Tailwind classes (max-w-48, max-h-48, rounded, object-cover)
      - Append to preview container (id + "-preview")
      - Store cleanup function to revoke URL later
   e. **Upload the file**: call fetch.Upload with:
      - URL: props.UploadURL (or default "/__gux_api/upload")
      - File: file (js.Value, stays in JS memory)
      - OnProgress: update progress bar in progress container
   f. **Progress display**: create/update a progress bar element in the progress container:
      - Outer div with bg-gray-200 rounded-full h-2.5 w-full
      - Inner div with bg-blue-600 rounded-full h-2.5, width set to percentage
      - Update aria-valuenow on progress bar
      - Update screen reader status (id + "-status") with "Uploading: X%"
   g. **On upload complete**:
      - If response.OK: parse response body as JSON to extract UploadResult fields, show success state (filename + remove button), call props.OnUploadComplete if set, announce "Upload complete" to status
      - If !response.OK: show error from response body, call props.OnError if set
   h. **Remove button**: when shown (after successful upload or when Value is set), clicking it clears the preview, resets the input, and calls props.OnRemove if set

5. **matchMimePattern(mimeType, pattern string) bool:**
   - If pattern ends with "/*", check prefix match
   - Otherwise exact match
   - Same logic as research doc

6. **Helper: setElementContent(id, html string)** -- gets element by ID, sets innerHTML
7. **Helper: clearElement(id string)** -- gets element by ID, sets innerHTML to ""

IMPORTANT implementation notes:
- Run fetch.Upload in a goroutine (go func(){...}()) so the OnMount callback returns immediately and doesn't block rendering
- Release js.FuncOf callbacks where possible, but event listeners on long-lived elements can be left (they'll be cleaned up on navigation via OnUnmount)
- The file js.Value is passed directly to fetch.Upload -- never use js.CopyBytesToGo
- For the progress OnProgress callback, update DOM directly (getElementById + style.width) since this runs outside gux's render cycle
- Encode/decode UploadResult JSON manually with js.Global().Get("JSON").Call("parse", resp.Body) or use encoding/json on resp.Body string
