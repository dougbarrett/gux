  <name>Task 1: Create fetch/upload.go (WASM upload with XHR progress)</name>
  <files>fetch/upload.go</files>
  <action>
Create fetch/upload.go with build tag `//go:build js && wasm`.

Define UploadOptions struct:
- URL string (upload endpoint, default "/__gux_api/upload")
- File js.Value (JavaScript File object -- stays in JS heap)
- FieldName string (form field name, default "file")
- OnProgress func(loaded, total int64) (progress callback, optional)
- ExtraFields map[string]string (additional form fields to append, optional)

Define UploadResult struct:
- Key string `json:"key"` (storage key)
- URL string `json:"url"` (serving URL)
- Filename string `json:"filename"` (original name)
- Size int64 `json:"size"` (file size in bytes)
- ContentType string `json:"content_type"` (detected MIME type)

Implement Upload(opts UploadOptions) (*Response, error):
1. Create FormData via js.Global().Get("FormData").New()
2. Append file: formData.Call("append", fieldName, opts.File) -- this keeps bytes in JS land
3. Append any ExtraFields
4. Create XMLHttpRequest via js.Global().Get("XMLHttpRequest").New()
5. BEFORE calling xhr.open(), attach upload.progress listener if OnProgress != nil:
   - upload := xhr.Get("upload")
   - Register "progress" event listener that reads lengthComputable, loaded, total
   - Call opts.OnProgress(loaded, total) when lengthComputable is true
6. Register "load" event listener:
   - Build Response from xhr.Get("status"), xhr.Get("statusText"), xhr.Get("responseText")
   - Set OK = status >= 200 && status < 300
   - Close done channel
7. Register "error" event listener:
   - Set error to "upload network error"
   - Close done channel
8. Call xhr.Call("open", "POST", opts.URL)
9. Get CSRF token via getCSRFToken() (already exported in fetch.go for WASM build)
   - If non-empty, call xhr.Call("setRequestHeader", "X-CSRF-Token", csrfToken)
10. Call xhr.Call("send", formData)
11. Block on done channel: <-done
12. Release all js.FuncOf callbacks (progressCb, loadCb, errorCb) to prevent memory leaks
13. Return response or error

IMPORTANT implementation details:
- Do NOT use js.CopyBytesToGo anywhere -- file bytes must stay in JavaScript
- Attach progress listener BEFORE xhr.open() to avoid browser bugs where events don't fire
- Use a done channel (make(chan struct{})) to synchronize the async XHR with Go's blocking call
- Release all js.FuncOf callbacks after done channel closes
- Default URL to "/__gux_api/upload" if opts.URL is empty
- Default FieldName to "file" if opts.FieldName is empty
