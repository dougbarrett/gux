  <name>Task 1: Create Toast components</name>
  <files>ui/toast.go</files>
  <action>
Create ToastContainer and Toast components following research patterns.

**ToastPosition type and constants:**
- ToastPosition string type
- ToastTopRight, ToastTopLeft, ToastBottomRight, ToastBottomLeft, ToastTopCenter, ToastBottomCenter
- toastPositionClasses map

**Position classes (fixed positioning):**
- ToastTopRight: "top-4 right-4"
- ToastTopLeft: "top-4 left-4"
- ToastBottomRight: "bottom-4 right-4"
- ToastBottomLeft: "bottom-4 left-4"
- ToastTopCenter: "top-4 left-1/2 -translate-x-1/2"
- ToastBottomCenter: "bottom-4 left-1/2 -translate-x-1/2"

**ToastContainerProps struct:**
- Position ToastPosition (default: ToastTopRight)
- Class string
- Children []core.Node (individual Toast components)

**ToastContainer function:**
- Fixed-position container for toasts
- ID="toast-container" for potential WASM targeting
- Base classes: "fixed z-50 flex flex-col gap-2"
- Position classes from toastPositionClasses
- ARIA live region in Extra:
  - role="status"
  - aria-live="polite"
  - aria-atomic="true"
- Renders Children (Toast components)

**ToastVariant type and constants:**
- ToastVariant string type
- ToastInfo, ToastSuccess, ToastWarning, ToastError

**toastVariantStyles struct and map:**
- Each variant has: bg (background), text (text color), icon (emoji/unicode)
- ToastInfo: "bg-blue-100 dark:bg-blue-900", "text-blue-800 dark:text-blue-200", icon: info circle or "i"
- ToastSuccess: "bg-green-100 dark:bg-green-900", "text-green-800 dark:text-green-200", icon: checkmark
- ToastWarning: "bg-yellow-100 dark:bg-yellow-900", "text-yellow-800 dark:text-yellow-200", icon: warning
- ToastError: "bg-red-100 dark:bg-red-900", "text-red-800 dark:text-red-200", icon: error/x

Use simple unicode icons that render well:
- Info: "i" in circle or just text
- Success: checkmark or "✓"
- Warning: "!" or "⚠"
- Error: "x" or "✕"

**ToastProps struct:**
- Message string (toast text content)
- Variant ToastVariant (default: ToastInfo)
- OnClose func() (optional close handler)
- Class string

**Toast function:**
- Individual toast notification
- Base classes: "px-4 py-3 rounded-lg shadow-lg flex items-center gap-3 min-w-64"
- Variant classes from toastVariantStyles
- Structure:
  1. Icon span with aria-hidden="true" (decorative)
  2. Message span with flex-1
  3. Conditional close button (only if OnClose provided)
- Close button: "opacity-70 hover:opacity-100 cursor-pointer", aria-label="Dismiss notification"
- Use core.If for conditional close button rendering
