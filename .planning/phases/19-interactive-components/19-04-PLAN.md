<task type="auto">
  <name>Task 1: Create Dropdown compound components</name>
  <files>ui/dropdown.go</files>
  <action>
Create Dropdown compound components following research patterns.

**DropdownPosition type and constants:**
- DropdownPosition string type
- DropdownBottomLeft, DropdownBottomRight, DropdownTopLeft, DropdownTopRight
- dropdownPositionClasses map for menu positioning

**Position classes:**
- DropdownBottomLeft: "top-full left-0 mt-1"
- DropdownBottomRight: "top-full right-0 mt-1"
- DropdownTopLeft: "bottom-full left-0 mb-1"
- DropdownTopRight: "bottom-full right-0 mb-1"

**DropdownProps struct:**
- Open bool (controls menu visibility)
- OnClose func() (called on backdrop click)
- Position DropdownPosition (default: DropdownBottomLeft)
- Class string (additional wrapper classes)
- Children []core.Node (DropdownTrigger and DropdownMenu)

**Dropdown function:**
- Wrapper div with "relative inline-block" for positioning context
- When Open=true, render an invisible backdrop div for outside clicks:
  - "fixed inset-0 z-40" - covers screen
  - OnClick calls props.OnClose (clicking outside closes menu)
- This backdrop approach handles "click outside to close" without global event listeners

**DropdownTriggerProps struct:**
- Open bool (for aria-expanded)
- OnClick func() (toggle handler)
- Class string
- Children []core.Node (usually a Button)

**DropdownTrigger function:**
- Wrapper div (inline-block)
- ARIA in Extra map:
  - aria-haspopup="menu"
  - aria-expanded=boolToAttr(props.Open)
- Applies OnClick handler
- Renders Children

**DropdownMenuProps struct:**
- Open bool (visibility control)
- Position DropdownPosition (for positioning classes)
- Class string
- Children []core.Node (DropdownItems)

**DropdownMenu function:**
- Div with role="menu"
- Base classes: "absolute z-50 min-w-48 bg-white dark:bg-gray-800 rounded-md shadow-lg border border-gray-200 dark:border-gray-700 py-1"
- Visibility: ConditionalClass(!props.Open, "hidden")
- Position: dropdownPositionClasses[props.Position] (default DropdownBottomLeft)
- Merge custom Class

**DropdownItemProps struct:**
- OnClick func()
- Disabled bool
- Destructive bool (for red styling on delete actions)
- Class string
- Children []core.Node

**DropdownItem function:**
- Button element with type="button"
- role="menuitem" in Extra
- Base classes: "w-full text-left px-4 py-2 text-sm transition-colors"
- Default styling: "text-gray-700 dark:text-gray-300 hover:bg-gray-100 dark:hover:bg-gray-700"
- Destructive styling: "text-red-600 dark:text-red-400 hover:bg-red-50 dark:hover:bg-red-900/20"
- Disabled styling: "text-gray-400 dark:text-gray-500 cursor-not-allowed"
- OnClick handler (only when not disabled)
- If disabled, add disabled="disabled"
