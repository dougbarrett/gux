<task type="auto">
  <name>Task 1: Create Modal compound components</name>
  <files>ui/modal.go</files>
  <action>
Create Modal component following research patterns in 19-RESEARCH.md.

**Modal types and constants:**
- ModalSize string type with constants: ModalSM, ModalMD, ModalLG, ModalXL, ModalFull
- modalSizeClasses map for width variants (max-w-sm through max-w-4xl)

**ModalProps struct:**
- Open bool (controls visibility via hidden class)
- OnClose func() (callback for X button and backdrop click)
- Title string (optional, sets aria-labelledby when present)
- Size ModalSize (default: ModalMD)
- Class string (additional classes for modal container)
- Children []core.Node (modal content)

**Modal function:**
- Always renders full structure (overlay + modal), visibility via CSS hidden class
- Overlay: fixed inset-0, bg-black/50, flex items-center justify-center, z-50
- Use ConditionalClass(!props.Open, "hidden") on overlay
- Modal container: bg-white dark:bg-gray-800, rounded-lg, shadow-xl, max-h-[90vh], flex flex-col
- ARIA: role="dialog", aria-modal="true"
- If Title provided: aria-labelledby="modal-title" and render H3 with ID
- Header section with title and close button (X) when either Title or OnClose provided
- Close button: text-gray-400 hover:text-gray-600, aria-label="Close"
- Backdrop OnClick should call OnClose (clicking outside closes)

**ModalContentProps struct:**
- Class string
- Children []core.Node

**ModalContent function:**
- Wrapper div with px-6 py-4 overflow-y-auto flex-1
- Merge custom Class

**ModalFooterProps struct:**
- Class string
- Children []core.Node

**ModalFooter function:**
- Wrapper div with px-6 py-4, border-t, flex justify-end gap-2
- For action buttons

**Use established patterns:**
- MergeClasses for all class construction
- ConditionalClass for state-dependent classes
- boolToAttr helper already exists in switch.go (same package)
- core.Attrs.Extra for ARIA attributes
