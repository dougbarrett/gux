<task type="auto">
  <name>Task 1: Create Tabs compound components</name>
  <files>ui/tabs.go</files>
  <action>
Create Tabs compound components following research patterns in 19-RESEARCH.md.

**TabsProps struct:**
- Class string
- Children []core.Node (TabList and TabPanels)

**Tabs function:**
- Simple wrapper div with "w-full" base class
- Merges custom Class

**TabListProps struct:**
- Class string
- Children []core.Node (Tab elements)

**TabList function:**
- Div with role="tablist" and aria-label="Tabs"
- Classes: "flex border-b border-gray-200 dark:border-gray-700 overflow-x-auto"
- Merge custom Class

**TabProps struct:**
- Active bool (is this tab selected)
- OnSelect func() (click handler)
- Disabled bool
- Class string
- Children []core.Node (tab label content)

**Tab function:**
- Renders as button element
- Base classes: "px-4 py-2 font-medium text-sm cursor-pointer border-b-2 transition-colors whitespace-nowrap"
- Focus classes: "focus:outline-none focus:ring-2 focus:ring-blue-500 focus:ring-inset"
- Active state: "border-blue-500 text-blue-600 dark:text-blue-400"
- Inactive state: "border-transparent text-gray-500 dark:text-gray-400 hover:text-gray-700 dark:hover:text-gray-300 hover:border-gray-300"
- Disabled state: "border-transparent text-gray-300 dark:text-gray-600 cursor-not-allowed"
- ARIA attributes in Extra map:
  - role="tab"
  - aria-selected=boolToAttr(props.Active)
  - tabindex="0" if active, "-1" if inactive (roving tabindex)
- If disabled, add disabled="disabled" and aria-disabled="true"
- OnClick handler from props

**TabPanelProps struct:**
- Active bool (is this panel visible)
- Class string
- Children []core.Node

**TabPanel function:**
- Div with role="tabpanel" and tabindex="0"
- Base classes: "mt-4"
- Use ConditionalClass(!props.Active, "hidden") to hide inactive panels
- Merge custom Class

**Note:** The page-level code controls which tab/panel is active via state. Components are pure renderers.
  </action>
