<task type="auto">
  <name>Task 1: Create Alert component</name>
  <files>ui/alert.go</files>
  <action>
Create Alert component following established ui package patterns.

**AlertVariant type and constants:**
- AlertVariant string type
- AlertInfo, AlertSuccess, AlertWarning, AlertError

**alertVariantStyles struct and map:**
Each variant has: bg, border, text, icon
- AlertInfo: "bg-blue-50 dark:bg-blue-950", "border-blue-200 dark:border-blue-800", "text-blue-800 dark:text-blue-200", icon: info circle unicode
- AlertSuccess: "bg-green-50 dark:bg-green-950", "border-green-200 dark:border-green-800", "text-green-800 dark:text-green-200", icon: checkmark
- AlertWarning: "bg-yellow-50 dark:bg-yellow-950", "border-yellow-200 dark:border-yellow-800", "text-yellow-800 dark:text-yellow-200", icon: warning
- AlertError: "bg-red-50 dark:bg-red-950", "border-red-200 dark:border-red-800", "text-red-800 dark:text-red-200", icon: error/x

Use unicode icons from toast.go pattern.

**AlertProps struct:**
- Message string (alert text content) - required
- Variant AlertVariant (default: AlertInfo)
- Title string (optional bold title before message)
- OnClose func() (optional close handler)
- Class string (additional classes)

**Alert function:**
- Inline alert box (not fixed like Toast)
- Base classes: "px-4 py-3 rounded-lg border flex items-start gap-3"
- Variant classes from alertVariantStyles (bg + border + text)
- ARIA: role="alert" in Extra map
- Structure:
  1. Icon span with aria-hidden="true" (decorative)
  2. Content div with flex-1:
     - Optional Title in strong tag
     - Message in span or p
  3. Conditional close button (only if OnClose provided)
- Close button: "ml-auto opacity-70 hover:opacity-100 cursor-pointer flex-shrink-0", aria-label="Dismiss"
- Default variant is AlertInfo when Variant is empty
