# v2.2 gux init Modernization

**Goal:** Update `gux init` to scaffold working apps using the modern `core/` framework instead of the deleted `components/` package.

**Started:** 2026-01-26
**Status:** In Progress

## Background

The current `gux init` command generates templates that use the old `components/` package which was deleted in v2.1. The scaffolded apps don't compile. This milestone updates the templates to use the modern `core/` framework with `ui/` components.

## What Users Get

After `gux init myapp`:

```
myapp/
├── app.go              # core.New(), DB, CRUD, routes
├── go.mod              # gux + gorm + sqlite
├── models/
│   └── item.go         # Example GORM model
└── pages/
    ├── home.go         # Landing page with ui.Card
    ├── items.go        # Items list with OnLoad + API
    └── item_new.go     # Create form with state + API
```

Then `gux dev` runs immediately — working app out of the box.

## Phase 27: gux init Templates

**Goal:** Replace all scaffold templates with core/-based versions

### Plan 27-01: Core Templates

Create the foundational templates:

- `templates/app.go.tmpl` — Entry point with core.New(), SetDB(), SetTitle(), CRUD(), Routes(), Run()
- `templates/go.mod.tmpl` — Module with gux, gorm, sqlite dependencies
- `templates/models/item.go.tmpl` — Example GORM model (Item with ID, Name, Description, timestamps)

**Requirements covered:** TMPL-01, TMPL-02, TMPL-03

### Plan 27-02: Page Templates

Create the page templates demonstrating key patterns:

- `templates/pages/home.go.tmpl` — Landing page with ui.Card, link to /items
- `templates/pages/items.go.tmpl` — List page with OnLoad(), API call, ui.Table
- `templates/pages/item_new.go.tmpl` — Form with state management, validation, API submission, r.Navigate()

**Requirements covered:** TMPL-04, TMPL-05, TMPL-06

### Plan 27-03: Scaffold Integration

Update scaffold.go and cleanup:

1. Remove old templates:
   - `templates/cmd/app/main.go.tmpl` (uses deleted components/)
   - `templates/cmd/server/main.go.tmpl` (not needed with core/)
   - `templates/internal/api/types.go.tmpl` (replaced by gux gen)
   - `templates/internal/api/example.go.tmpl` (replaced by gux gen)
   - `templates/Dockerfile.tmpl` (needs update for new structure)

2. Update scaffold.go:
   - New file list matching new template structure
   - Add `runGen(false)` call after file creation (to generate .gux/api/)
   - Update conflict detection for new file paths

3. Test: `gux init testapp && cd testapp && gux dev` works

**Requirements covered:** PROC-01, PROC-02, PROC-03, PROC-04, CLNP-01, CLNP-02, CLNP-03, CLNP-04
